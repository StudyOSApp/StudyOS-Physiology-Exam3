### Question 1

The measurement usually about 1°F higher than oral temperature is:

A. Skin temperature

C. Room temperature

**Correct answer: D. Rectal temperature**

**Explanation:** Rectal temperature generally runs about 1°F above oral temperature and more closely reflects core temperature.

### Question 2

The temperature most affected by the environment is:

A. Core temperature  
B. Hypothalamic temperature  
C. Skin temperature  
D. Deep-tissue temperature

**Correct answer: C. Skin temperature**

**Explanation:** Skin temperature changes with ambient conditions, blood flow, exercise, and sweating, while core temperature is regulated more tightly.

### Question 3

During exercise, core temperature remains stable when:

A. Skin temperature equals core temperature  
B. Heat production equals heat loss  
C. Sweating completely stops  
D. Metabolism falls to zero

**Correct answer: B. Heat production equals heat loss**

**Explanation:** Body temperature is stable when the rate of heat generation is balanced by the rate of heat transfer to the environment.

### Question 37

Why does a person feel cold and shiver as a fever begins?

A. Core temperature is above a lowered set point  
B. Sweating has already lowered the set point  
C. Skin temperature can no longer be detected

### Question 38

What causes flushing and sweating when a fever “breaks”?

A. The set point rises above the current core temperature  
B. Heat-loss mechanisms become permanently disabled  
C. The set point returns toward normal while core temperature remains high  
D. Pyrogen production increases sharply

**Correct answer: C. The set point returns toward normal while core temperature remains high**

**Explanation:** The body now senses itself as too warm and activates vasodilation and sweating to lower temperature.
