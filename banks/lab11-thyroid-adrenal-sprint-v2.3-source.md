### Question 1

Which sequence correctly traces the HPT axis?

A. TRH -> TSH -> T3/T4  
B. TSH -> TRH -> T3/T4  
C. T3/T4 -> TRH -> TSH  
D. TRH -> T3/T4 -> TSH  

**Correct answer: A. TRH -> TSH -> T3/T4**

**Explanation:** Hypothalamic TRH stimulates anterior-pituitary TSH, which stimulates thyroid T3 and T4 secretion.
